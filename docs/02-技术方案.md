## 1. 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 编程语言 | Python 3.12 | 开发快速，生态丰富，对中文支持好 |
| GUI 框架 | PyQt5 | 成熟稳定，原生 Windows 体验 |
| 本地数据库 | SQLite3 | 无需安装服务，零配置 |
| 图片处理 | Pillow (PIL) | 图片压缩与缩略图生成 |
| 剪贴板监听 | PyQt5.QtGui.QClipboard | 利用 Qt 自带的剪贴板信号 |

## 2. 为什么选这些技术？

- **Python**：适合快速开发，对小白友好，后续好维护
- **PyQt5**：界面美观，自带剪贴板监听信号，省去调用 Windows API
- **SQLite**：轻量级嵌入式数据库，一个文件搞定所有数据存储
- **Pillow**：Python 图片处理标准库，成熟稳定

## 3. 数据模型设计

### 3.1 数据库表结构

```sql
CREATE TABLE clipboard_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content_type TEXT NOT NULL,      -- 'text' 或 'image'
    text_content TEXT,               -- 文字内容（type=text 时）
    image_path TEXT,                 -- 图片文件路径（type=image 时）
    thumbnail_path TEXT,             -- 缩略图路径
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,  -- 创建时间
    is_pinned INTEGER DEFAULT 0,     -- 是否置顶 0/1
    is_expired INTEGER DEFAULT 0     -- 是否过期标记 0/1
);
```

### 3.2 数据结构说明

- `content_type`：区分文字和图片，便于 UI 渲染不同卡片
- `text_content`：文字内容全文存储，支持搜索
- `image_path`：图片保存到本地 `data/images/` 目录
- `thumbnail_path`：缩略图保存到 `data/thumbnails/`，减少 UI 卡顿
- `is_pinned`：置顶记录在前端排序时优先展示
- `is_expired`：设置存储期限后，后台定时任务检查并标记过期

## 5. 剪贴板监听机制

利用 PyQt5 的 `QClipboard.dataChanged` 信号：

```python
from PyQt5.QtWidgets import QApplication
app = QApplication([])
clipboard = app.clipboard()
clipboard.dataChanged.connect(on_clipboard_change)
```

当剪贴板内容发生变化时，自动触发回调，判断内容类型（文字/图片），存入数据库和文件系统。

## 6. 图片存储方案

- 原始图片 → `data/images/{id}.png`
- 缩略图（最大 200x200） → `data/thumbnails/{id}.png`
- 使用 Pillow 进行图片缩放和质量压缩
