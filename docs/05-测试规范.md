# 05 - 测试规范

> 版本：v1.0 | 最后更新：2026-05-13

---

## 1. 测试原则

- 每个功能模块完成后立即测试
- 修 bug 后回归测试相关功能
- 最终打包前做全量功能测试

## 2. 功能测试清单

### 2.1 剪贴板监听

| 测试项 | 预期结果 |
|--------|----------|
| 复制文字 | 软件自动记录文字内容 |
| 复制图片 | 软件自动保存图片并生成缩略图 |
| 多次连续复制 | 每条记录都正确保存 |
| 复制空内容 | 忽略空内容，不记录 |
| 重复内容 | 正常记录（允许重复） |

### 2.2 数据存储

| 测试项 | 预期结果 |
|--------|----------|
| SQLite 数据库创建 | 首次运行自动创建 clipboard.db |
| 图片文件存储 | 图片保存到 data/images/，不丢失 |
| 数据持久化 | 关闭再打开软件，数据仍在 |

### 2.3 UI 界面

| 测试项 | 预期结果 |
|--------|----------|
| 卡片展示 | 卡片按时间倒序排列 |
| 置顶操作 | 置顶卡片固定在最前，有标记 |
| 删除操作 | 卡片从列表移除，数据库删除 |
| 全文搜索 | 输入关键词实时筛选匹配卡片 |
| 期限设置切换 | 切换 1/3/5 天后过期标记更新 |
| 一键清理过期 | 所有过期卡片被删除 |
| 重新复制 | 点击卡片后内容回到剪贴板 |

### 2.4 边界测试

| 测试项 | 预期结果 |
|--------|----------|
| 复制内容过长（>10000字） | 截断显示，完整存储 |
| 图片过大（>10MB） | 压缩后存储，不影响性能 |
| 数据库记录超过 10000 条 | 列表加载流畅，不卡顿 |
| 软件重复快速启动退出 | 资源正常释放，不报错 |
| 搜索无结果 | 显示"未找到匹配内容"提示 |

## 3. 测试流程

```
开发新功能 → 功能测试 → 通过 → 继续开发
                  ↓ 不通过
              修复 bug → 重新测试
```

## 4. 验收标准

- ✅ 所有功能测试项通过
- ✅ 软件可正常启动和关闭
- ✅ 打包后的 .exe 可独立运行（无需 Python 环境）
- ✅ 连续使用 1 小时无崩溃
