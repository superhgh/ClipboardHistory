# 01 - 开发需求文档

> 版本：v1.0 | 最后更新：2026-05-13

---

## 1. 项目概述

开发一个运行在 Windows 10 上的历史粘贴板软件，自动记录用户复制的内容（文字和图片），支持按时间浏览、搜索、管理历史记录。

## 2. 目标用户

不懂编程的普通电脑用户，追求简单易用。

## 3. 功能需求

### 3.1 核心功能

| 编号 | 功能 | 说明 |
|------|------|------|
| F01 | 自动记录复制内容 | 软件打开后，自动监听并记录剪贴板中的文字和图片 |
| F02 | 存储期限设置 | 用户可设置 1天 / 3天 / 5天 的存储期限 |
| F03 | 过期标记 | 超过存储期限的内容标记为"已过期"，但不自动删除 |
| F04 | 时间倒序展示 | 所有记录按时间倒序排列，最新的在最上面 |
| F05 | 卡片操作 | 每条记录以卡片形式展示，支持：重新复制、置顶、删除 |
| F06 | 全文搜索 | 搜索框输入关键词，实时筛选匹配的文字记录 |
| F07 | 一键清理过期 | 一键删除所有已标记过期的内容 |

### 3.2 交互流程

```
用户复制内容 → 软件自动捕获 → 存入本地数据库 → UI 实时刷新展示
用户打开软件 → 浏览卡片列表 → 搜索 / 置顶 / 删除 / 重新复制
用户设置期限 → 过期卡片标记 → 可一键清理
```

## 4. 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| N01 | 启动速度 | 软件启动后在 3 秒内可正常使用 |
| N02 | 资源占用 | 后台运行内存占用不超过 100MB |
| N03 | 数据安全 | 所有数据存储在本地，不上传网络 |
| N04 | 稳定性 | 连续运行 7 天不崩溃、不卡顿 |

## 5. 边界与限制

- 仅支持 Windows 10 操作系统
- 图片支持常见格式（PNG、JPG、BMP）
- 不支持文件复制记录（仅文字和图片）
- 软件关闭后不记录（无开机自启）
