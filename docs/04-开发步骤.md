# 04 - 开发步骤

> 版本：v1.0 | 最后更新：2026-05-13

---

## 开发路线图

```
Phase 1 ───→ Phase 2 ───→ Phase 3 ───→ Phase 4
 骨架搭建      核心功能       UI 开发      集成测试
```

---

## Phase 1：项目骨架搭建

**目标**：搭建完整的项目文档体系和开发环境。

| 步骤 | 任务 | 说明 |
|------|------|------|
| 1.1 | 创建文档体系 | 编写 5 份标准文档（需求、技术、设计、步骤、测试） |
| 1.2 | 搭建日志系统 | 创建开发日志模板，每日记录 |
| 1.3 | 配置 CLAUDE.md | 项目级指令文件，指引文档路径 |
| 1.4 | 初始化 Python 环境 | 创建虚拟环境、requirements.txt |
| 1.5 | 验证环境 | 确认 PyQt5 可正常运行 |

---

## Phase 2：核心功能实现

**目标**：完成数据层和剪贴板监听功能，不涉及界面。

| 步骤 | 任务 | 说明 | 涉及文件 |
|------|------|------|----------|
| 2.1 | 数据库模块 | SQLite 建表、CRUD 操作 | `src/database.py` |
| 2.2 | 剪贴板监听模块 | 监听复制事件，区分文字/图片 | `src/clipboard_monitor.py` |
| 2.3 | 数据管理器 | 数据处理（排序、搜索、过期标记） | `src/data_manager.py` |
| 2.4 | 单元测试 | 测试各模块功能 | `tests/` |

---

## Phase 3：UI 界面开发

**目标**：完成所有界面组件。

| 步骤 | 任务 | 说明 | 涉及文件 |
|------|------|------|----------|
| 3.1 | 主窗口 | 整体布局、样式加载 | `src/main_window.py` |
| 3.2 | 卡片组件 | 文字卡片、图片卡片 | `src/card_widget.py` |
| 3.3 | 搜索框 | 实时搜索、清除按钮 | `src/search_bar.py` |
| 3.4 | 期限设置 | 单选按钮组 | `src/expiry_settings.py` |
| 3.5 | 工具栏 | 一键清理、统计信息 | `src/toolbar.py` |

---

## Phase 4：集成与测试

**目标**：联调所有模块，完成测试，打包发布。

| 步骤 | 任务 | 说明 |
|------|------|------|
| 4.1 | 模块集成 | UI 绑定数据层、剪贴板监听启动/停止 |
| 4.2 | 功能测试 | 覆盖所有功能点 |
| 4.3 | 异常处理 | 图片损坏处理、数据库异常处理 |
| 4.4 | 性能优化 | 大数据量下的流畅度 |
| 4.5 | 打包发布 | 使用 PyInstaller 打包为 .exe |
